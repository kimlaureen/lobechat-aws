# Q3 — Cost model + unit economics

## Assumptions

**Usage per active user per month** (22 business days — internal enterprise tool, not consumer):

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| Messages/user/day | 20 | Mixed user base: power users 30–40, occasional users 5–10 |
| Input tokens/message | 500 | System prompt ~150 + history ~150 + RAG context ~100 + user message ~100 |
| Output tokens/message | 800 | Detailed assistant replies (~600 words); dominant cost driver |
| RAG queries/message | 30% | Short follow-ups and direct MCP commands bypass Qdrant |
| File uploads/user/month | 2 × 5 MB = 10 MB | PDFs and images for RAG ingestion; occasional behaviour |
| Data retention | Postgres indefinite; S3 uploads 12 months then Glacier; Qdrant grow-only | |

**LLM provider:** OpenRouter with Claude Haiku 3.5. Prices at openrouter.ai/models (May 2026): input $0.0008/1K tokens, output $0.004/1K tokens. No GPU infrastructure required — OpenRouter exposes an OpenAI-compatible endpoint that LobeChat consumes identically to how it would consume vLLM.

**Scope:** all prices are AWS eu-west-1 on-demand list prices. Reserved Instances (1-year no-upfront) reduce EC2 and RDS by ~35% and are noted as a cost lever but not applied to the baseline table.

**Token volumes per scale:**
- 10 MAU: 10 × 20 × 22 = **4,400 messages** → 2.2M input / 3.52M output tokens
- 100 MAU: 100 × 20 × 22 = **44,000 messages** → 22M input / 35.2M output tokens
- 1000 MAU: 1000 × 20 × 22 = **440,000 messages** → 220M input / 352M output tokens

## Top 3 cost drivers at 1000 MAU

**#1 — LLM output tokens: $1,408/month (62% of total)**

Output tokens at 800/message × 440,000 messages = 352M tokens/month. At $0.004/1K, this single line item exceeds the entire infrastructure bill. It is the only cost that scales linearly with users — every additional 100 MAU adds $140.80. The output-to-input price ratio (5:1 for Haiku) combined with an output-heavy assumption (800 tokens out vs 500 in) means output dominates token spend entirely. Input tokens cost $176/month; output tokens cost $1,408. Model choice and response length — not instance sizing — determine the bill at this scale.

**#2 — EC2 compute: $417/month (18% of total)**

Two instances: `m6i.2xlarge` ($312) for the app tier and `r6i.large` ($105) dedicated to Qdrant. The Qdrant instance is isolated because its HNSW index for a 200K-chunk corpus requires ~12 GB RAM to serve queries without thrashing. Shared with MCPHub's stdio subprocess forks (15–20 simultaneous at peak), the index is evicted from RAM and search latency spikes 100×. EC2 cost is fixed — identical whether 500 or 1000 users are active. It does not compound with users.

**#3 — RDS Multi-AZ: $224.50/month (10% of total)**

Multi-AZ doubles the RDS instance price: `db.t4g.large` Single-AZ is $0.146/hr; Multi-AZ is $0.292/hr. The additional $107/month buys automatic ~60-second failover. At 1000 MAU, a Postgres outage simultaneously breaks sessions, chat history, and Casdoor authentication for every user. The data volume is modest — 440K messages × 2 KB = 880 MB/month new data — so the cost is entirely instance-driven, not storage-driven. 100 GB allocated storage ($11.50) provides years of headroom.

## Cost-cutting levers

**Lever 1 — Cap output token length via system prompt**

**Saving: $704/month — 31% of total bill**

Add one instruction to every agent system prompt: *"Be concise. Limit responses to 4 paragraphs or fewer unless the user explicitly requests detail."* This reduces average output from 800 tokens to 400 tokens.

- Current output cost: 352M tokens × $0.004/1K = $1,408/month
- After cap (176M tokens): $704/month
- **Saving: $704/month**

No infrastructure change. One line per agent system prompt in the LobeChat UI.

**SLO/UX trade-off:** the RAG Sage agent synthesises answers from multiple Qdrant corpus chunks — a task that naturally requires 600–800 tokens to be complete. At a 400-token cap, users asking for comprehensive incident analysis or full architecture reviews receive truncated output and must issue follow-up prompts. Track average follow-up turns per session: if users average more than 1.5 follow-ups on synthesis tasks, relax the cap to 600 tokens (saving ~$352/month, still above the 15% threshold).

**Lever 2 — Route simple queries to GPT-4o mini, complex queries to Claude Haiku**

**Saving: $536/month — 23.5% of total bill**

Approximately 40% of messages are simple: short follow-ups in ongoing conversations, single-lookup AWS queries, direct commands with no multi-step reasoning. Route these to GPT-4o mini ($0.00015/1K input, $0.00060/1K output via OpenRouter). Keep Haiku for tool-call-heavy and RAG-grounded queries (60% of messages).

- Simple (176K messages) on GPT-4o mini: 88M input × $0.15/1M + 140.8M output × $0.60/1M = **$97.68**
- Complex (264K messages) on Haiku: 132M × $0.80/1M + 211.2M × $4/1M = **$950.40**
- Total: $1,048 vs baseline $1,584 → **saving $536/month**

Implementation: LobeChat supports per-agent model selection. Assign the general chat agent to GPT-4o mini; assign RAG Sage and Cloud Diagram Assistant (which always invoke MCP tools) to Haiku. OpenRouter exposes both models at the same API endpoint.

**SLO/UX trade-off:** GPT-4o mini has weaker multi-step tool-calling reliability than Claude Haiku 3.5 for MCP orchestration. A query misclassified as simple that requires sequential tool calls (list EC2 instances then check CloudWatch for each) will underperform or silently skip tool calls. Monitor tool-call success rate per model. If GPT-4o mini falls below 85% on MCP tool calls, tighten the classifier or reduce the simple-query allocation to 25%, reducing the saving to ~$335/month (14.7% — marginally below threshold) in exchange for reliability.

## Unit economics

| Scale | Monthly total | Per user/month | Infrastructure overhead/user | Token cost/user |
|-------|--------------|----------------|------------------------------|----------------|
| 10 MAU | ~$160 | **$16.00** | $14.42 | $1.58 |
| 100 MAU | ~$405 | **$4.05** | $2.47 | $1.58 |
| 1000 MAU | ~$2,273 | **$2.27** | $0.69 | $1.58 |

The variable token cost per user is constant at all scales: $1.58/user/month (440 messages × $0.0036/message). Everything above $1.58 is fixed infrastructure divided by N users.

**Where the curve breaks:** the drop from 10 to 100 MAU is 75% (from $16.00 to $4.05) — the sharp inflection. The drop from 100 to 1000 MAU is 44% (from $4.05 to $2.27), meaningful but diminishing. Beyond ~500 MAU, infrastructure overhead per user ($0.69) becomes rounding error and per-user cost asymptotes toward the $1.58 token floor. Adding users changes the total bill but barely moves the per-user figure.

**Minimum viable user base:** AWS cost alone makes self-hosting cheaper than ChatGPT Enterprise ($30/user/month) at as few as 5 users. But this ignores ops overhead — maintaining Docker Compose, RDS, CloudWatch, Qdrant snapshots, and secret rotation realistically costs 3–5 engineer-hours/month, or ~$300/month at $80/hr loaded. Including ops, total cost at 100 MAU is $705/month ($7.05/user), and break-even vs ChatGPT Enterprise occurs at approximately **25–30 MAU**. Below that threshold, the ops burden is not justified by cost savings unless data sovereignty is a hard non-negotiable.

## Pricing recommendation

To cover full cost + 50% gross margin at 100 MAU, including AWS infrastructure and ops overhead:

| Component | Monthly |
|-----------|---------|
| AWS infrastructure | $405 |
| Ops overhead (4 hrs × $80/hr) | $320 |
| **Total cost** | **$725** |
| Cost per user (100 MAU) | $7.25 |
| **Price at 50% margin** | **$14.50/user/month → $15/user/month** |

At $15/user/month and 100 MAU: revenue $1,500/month, gross profit $775/month (52% margin).

$15/user/month is half of ChatGPT Enterprise and half of Microsoft Copilot (both $30/user/month). The pricing is defensible on two grounds: cost (50% cheaper than alternatives) and capability (custom MCP tool integrations, self-hosted RAG over proprietary corpora, data that never leaves the customer's AWS account — none of which SaaS alternatives offer at any price).

The price should include a **minimum commitment of 25 users**. Below 25 MAU, fixed ops overhead makes each customer unprofitable at $15/user/month. As MAU grows beyond 100, infrastructure overhead per user falls toward $0.69 while the $15 price holds — margin widens with scale without a price increase. At 1000 MAU, revenue is $15,000/month against a $2,573 fully-loaded cost ($2,273 AWS + $300 ops), yielding a 83% gross margin.
